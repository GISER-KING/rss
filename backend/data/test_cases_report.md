# 生态岸线详解

## 一、生态岸线的定义

**生态岸线**是指依托河湖自然形态，充分利用河湖周边地带，因地制宜建设的具有生态保护功能、亲水功能和景观功能的岸线类型。其核心理念是**保护优先、人水和谐共生**，在确保防洪、供水、生态安全的前提下，兼顾公共休闲等需求。

根据检索到的政策文献，生态岸线建设需遵循以下法律法规依据：

| 法律法规 | 相关内容 |
|---------|---------|
| 《中华人民共和国水法》 | 水资源保护与合理利用 |
| 《中华人民共和国防洪法》 | 防洪安全与行洪通畅 |
| 《中华人民共和国河道管理条例》 | 河道管理与岸线管控 |
| 《水库大坝安全管理条例》 | 水利工程安全管理 |

---

## 二、生态岸线的主要特征

### 2.1 自然性特征
- **顺应原有地形地貌**：不改变河道走向，不大挖大填
- **保持自然风貌**：不进行大面积硬化，尽量维持岸线自然状态
- **保护行洪断面**：不束窄或减少行洪、纳潮断面

### 2.2 生态性特征
- **植被配置科学**：植物品种、布局、高度、密度等不得影响行洪通畅
- **生态廊道建设**：推进沿河沿湖绿色生态廊道建设，打造滨水生态空间
- **生物多样性保护**：为水生和陆生生物提供栖息环境

### 2.3 功能性特征
- **亲水功能**：建设亲水生态岸线，打造绿色游憩走廊
- **安全功能**：除防浪林、护堤林外不得种植影响行洪的林木
- **复合功能**：兼顾航运、发电、减淤、文化、公共休闲等需求
